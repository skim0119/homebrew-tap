# Skim0119 Tap

## How do I install these formulae?

`brew install skim0119/tap/<formula>`

Or `brew tap skim0119/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "skim0119/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
